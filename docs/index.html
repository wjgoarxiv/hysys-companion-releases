      Aspen HYSYS를 말로 다루는 앱이에요An app that runs Aspen HYSYS from plain words

      HYSYS 옆에서 쓰는 Windows 데스크톱 앱이에요. 새 케이스를 만들고, 열린 케이스에 묻고, 말로 바꿔요.A Windows desktop app that works beside Aspen HYSYS. Start new cases, ask about the open one, and change it by describing the change.

      설치하고 HYSYS에 연결해요Install, then connect HYSYS

      1. 릴리스 페이지에서 설치 파일을 받아요.Download the installer from the release page.
      2. 받은 파일의 SHA-256을 릴리스 페이지의 값과 비교해요.Compare the file's SHA-256 with the value on the release page.
      3. 설치 파일을 실행해요. Python은 따로 설치하지 않아도 돼요.Run the installer. No separate Python install is needed.
      4. 앱에서 'HYSYS 켜기'를 누르면 켜지고 자동으로 연결돼요.Press 'Start HYSYS' in the app. It starts and connects on its own.
