# 이름과 로고 정책 · Name and logo policy

**한국어** — HYSYS Companion의 코드는 Apache License 2.0을 따르지만, 이 라이선스는 이름과 로고까지 허락하지 않아요(라이선스 6조). "HYSYS Companion"이라는 이름, 로고, WOOJIN GO 로고는 Woojin Go(@wjgoarxiv)에게 있어요.

- 코드를 고쳐서 다시 배포할 때는 다른 이름과 아이콘을 쓰고, README와 정보 화면에 "HYSYS Companion을 바탕으로 고친 버전"이라고 밝혀 주세요. `LICENSE`와 `NOTICE`는 그대로 남겨야 해요.
- 고친 버전을 원본이나 공식 빌드, 또는 자기가 처음 만든 것처럼 내놓으면 안 돼요.
- 공식 설치 파일은 이 저장소의 [Releases](https://github.com/wjgoarxiv/hysys-companion-releases/releases)에만 있어요. 릴리스마다 SHA-256 값과 `.sig` 서명 파일이 함께 올라가고, 앱의 업데이트 기능은 서명이 맞는 설치 파일만 설치해요.
- 정책을 어긴 사본은 [SECURITY.md](SECURITY.md)의 비공개 신고 양식으로 알려 주세요.

**English**

The code of HYSYS Companion is licensed under the Apache License 2.0. That license
covers the code only. Section 6 of the license says it grants no right to use the
author's names or marks, so the name **HYSYS Companion**, the HYSYS Companion logo
and the WOOJIN GO lockup stay with Woojin Go (@wjgoarxiv).

## What you may do

- Use, change and share the code under the Apache License 2.0.
- Say that your project is "based on HYSYS Companion" or "a fork of HYSYS Companion".
- Use the name to refer to the original project, for example in a review or a talk.

## What needs written permission

- Shipping a changed version under the name HYSYS Companion, or a name or logo that
  could be confused with it.
- Presenting a changed version as the original, as an official build, or as your own
  original work.
- Using the logo or the WOOJIN GO lockup in your product, installer or store listing.

A fork must use its own name and icon, keep the `LICENSE` and `NOTICE` files, and
say in its README and About screen that it is based on HYSYS Companion and has been
changed.

## Official builds

The only official installers are published at
<https://github.com/wjgoarxiv/hysys-companion-releases/releases>. Each release lists
the installer's SHA-256 and carries a `.sig` file made with the author's release key;
the app's own updater installs only installers with a valid signature.
